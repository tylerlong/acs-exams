## Classification Method

The ten additional exams below were checked question by question. Each question is assigned once using the broad USNCO topics above. Where a question spans topics, its exam section supplies the tie-breaker; these are exam-topic groupings rather than exclusive concept labels. The checked content column lists the six questions in ascending order within each range.

Examples of overlap: 2024 Q47 compares reduction potentials down group 10 (Atomic Structure/Periodicity); 2018 Q55 counts pi bonds in propyne (Organic/Biochemistry); 2019 Q3 uses gas-mixture composition to calculate partial pressure (Stoichiometry/Solutions). Half-life/rate calculations belong to Kinetics, while nuclear transformations belong to Atomic Structure/Periodicity.
